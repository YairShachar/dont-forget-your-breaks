North star

From a break reminder → an "Attention Sanctuary" / adaptive rhythm companion: the calm layer that protects your attention, makes rest a moment you arrive at, and mirrors your rhythm back as something beautiful. The moat is the local, sensor-driven event log + a genuinely calm, kind design sensibility. (Full backlog: docs/vision.md)

Engineering health & risks

  • No CI (#13). Tests are green (233) but run only on your machine — no gate on push/PR.
  • Single-file UI. launch.py is large; logic is cleanly factored into dfyb/, UI modularization (#11) is ongoing.
  • Motion ceiling. Tk can't do smooth resize/accordion animation — documented; SwiftUI reconsideration is #27.
  • Implicit deps (#14). No requirements file yet; customtkinter/pyobjc/pillow are assumed.
  • Strong test base & clean core. Pure logic (scheduler, sensors, event log, insights) is framework-agnostic and portable to a future native UI.
  • Release pipeline works. release.sh → DMG + Homebrew tap; shipping steadily (v1.6 → v1.8.3).
