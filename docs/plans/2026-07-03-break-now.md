# "Break now" Manual Trigger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Human-in-the-loop:** Task 1 ends with a **live click check** (the logic is Tk-bound UI glue that reuses already-tested methods, so it's launch-verified, not unit-tested). The controller pauses there for the human to confirm.

**Goal:** Add a discoverable "Break now" button to each break's header that immediately starts that break and resets its countdown (issue #10).

**Architecture:** Thin reuse of existing methods. `BreakApp.break_now(config)` = `reset_timer()` + `trigger_break()` (both already exist and are used by the timer loop) + a UI refresh. `BreakConfigPanel` gains an `on_break_now` callback (mirroring its existing `on_test`) and a header button. No new pure logic, no new dependencies, no new prefs.

**Tech Stack:** Python 3, CustomTkinter, pytest.

**Spec:** `~/daily/specs/2026-07-03-break-now-design.md`

## Global Constraints

- **Break now resets only its own break's countdown** (to the full interval) and shows the popup **immediately**, bypassing the scheduler's fullscreen/away deferral (it calls `trigger_break` directly, which does not go through the timer loop's `advance`). Works in any app state (Idle / Working / Paused).
- **Keep the existing "Test" button** (expanded settings) unchanged — it previews the popup without resetting the timer.
- **No hardcoded visual values** — reuse existing tokens (`BUTTON_HEIGHT_SMALL`, `CORNER_RADIUS_INPUT`, `COLORS`, `FONT_SIZES`, `FONT_FAMILY`); inline button `width` is consistent with the existing "Test"/"Play" buttons.
- **Tests:** `pytest`, run `.venv/bin/python -m pytest -q`. Baseline: **79 passed** (unchanged — this task adds no unit tests; it is launch-verified).
- **Commits:** conventional-commit summary only, no body, no co-author trailer.

### Task 1: "Break now" method + header button (launch-verified)

**Files:**
- Modify: `launch.py` — `BreakApp.break_now` (new, after `test_break`); `BreakConfigPanel.__init__` (new `on_break_now` param); `BreakConfigPanel._build_ui` (header button); panel instantiation (pass `self.break_now`).

**Interfaces:**
- Consumes (existing): `BreakConfig.reset_timer()`, `BreakApp.trigger_break(config)`, `BreakApp.update_ui()`, `BreakConfigPanel.on_test` pattern.
- Produces: `BreakApp.break_now(config)`; `BreakConfigPanel(parent, config, on_test, on_break_now)`.

- [ ] **Step 1: Add the `break_now` method**

In `launch.py`, find `BreakApp.test_break`:
```python
    def test_break(self, config):
        """Test a specific break configuration."""
        self.trigger_break(config)
```
and add immediately after it:
```python
    def break_now(self, config):
        """Take this break immediately: reset its countdown and show the popup.

        Manual/explicit action — bypasses the scheduler's fullscreen/away
        deferral (trigger_break shows the popup directly, not via the timer loop).
        """
        config.reset_timer()
        self.trigger_break(config)
        self.update_ui()
```

- [ ] **Step 2: Add the `on_break_now` parameter to `BreakConfigPanel`**

In `launch.py`, find:
```python
    def __init__(self, parent, config, on_test):
        super().__init__(
            parent,
            corner_radius=CORNER_RADIUS_PANEL,
            fg_color=COLORS['bg_panel']
        )
        self.config = config
        self.on_test = on_test
```
and change the signature + store the new callback:
```python
    def __init__(self, parent, config, on_test, on_break_now):
        super().__init__(
            parent,
            corner_radius=CORNER_RADIUS_PANEL,
            fg_color=COLORS['bg_panel']
        )
        self.config = config
        self.on_test = on_test
        self.on_break_now = on_break_now
```

- [ ] **Step 3: Add the "Break now" button to the header**

In `launch.py`, in `BreakConfigPanel._build_ui`, find:
```python
        self.header_timer.pack(side="left", padx=(0, 12))
        self.header_timer.pack_forget()  # Hidden by default (shown when collapsed)

        # Chevron indicator (always on far right)
```
and insert the button between the timer and the chevron comment:
```python
        self.header_timer.pack(side="left", padx=(0, 12))
        self.header_timer.pack_forget()  # Hidden by default (shown when collapsed)

        # Break now button (always visible in the header for quick access)
        self.break_now_btn = ctk.CTkButton(
            header_right,
            text="Break now",
            command=lambda: self.on_break_now(self.config),
            width=90, height=BUTTON_HEIGHT_SMALL,
            corner_radius=CORNER_RADIUS_INPUT,
            fg_color="transparent",
            border_width=1,
            border_color=COLORS['border'],
            hover_color=COLORS['bg_hover'],
            font=ctk.CTkFont(family=FONT_FAMILY, size=FONT_SIZES['helper'])
        )
        self.break_now_btn.pack(side="left", padx=(0, 12))

        # Chevron indicator (always on far right)
```
(The header's click-to-toggle is bound only to `header_frame` / `header_label` / `chevron`, so this button fires `on_break_now`, not the expand toggle.)
